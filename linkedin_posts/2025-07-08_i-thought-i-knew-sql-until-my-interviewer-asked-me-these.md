"I thought I knew SQL... until my interviewer asked me these!"
 SQL interviews can be tricky! Here are some thought-provoking questions that tested my knowledge:
 1️⃣ How do you pivot rows into columns in SQL?
 2️⃣ What’s the difference between INNER JOIN and CROSS JOIN?
 3️⃣ How can you delete duplicate rows while keeping only the latest record?
 4️⃣ What are common table expressions (CTEs), and how do they differ from subqueries?
 5️⃣ How do you identify and remove orphan records between two related tables?
 6️⃣ How do you randomly sample 10% of rows from a large table?
 7️⃣ How can you generate running totals without using window functions?
 8️⃣ What’s the difference between RANK(), DENSE_RANK(), and ROW_NUMBER()?
 9️⃣ How do you perform case-insensitive searches in SQL?
 🔟 How do you convert a comma-separated string into individual rows?
 1️⃣1️⃣ How do you find the second highest salary in a department without using TOP or LIMIT?
 1️⃣2️⃣ What’s the difference between DELETE and TRUNCATE?
 1️⃣3️⃣ How can you handle NULLs in JOIN conditions effectively?
 1️⃣4️⃣ How would you implement Type 2 Slowly Changing Dimensions using SQL?
 1️⃣5️⃣ How do you traverse a parent-child hierarchy using SQL?
 1️⃣6️⃣ What are the advantages and disadvantages of indexing in SQL?
 1️⃣7️⃣ How can you track changes to sensitive columns like salary or status using SQL only?
 1️⃣8️⃣ What’s the use of CROSS APPLY and OUTER APPLY in SQL Server?
 1️⃣9️⃣ How do you calculate moving averages in SQL?
 2️⃣0️⃣ How do you optimize queries involving multiple OR conditions?
SQL is powerful, but the right questions make you think beyond the basics.
 Which of these do you find the trickiest? Let’s discuss!
