## Content

If I started data analytics today, I'd be hired in 90 days. 

Here's the exact roadmap:

╰┈➤WEEK 1-2: Foundation 
Do this:
✔ Learn Google Sheets basics and Ms Excel (3 hours max)
✔ Master these 5 formulas: VLOOKUP, IF, SUMIFS, PIVOT TABLES, FILTER
✔ Build ONE simple budget tracker for yourself

➔ Why: Employers care about problem-solving, not formula memorization.

╰┈➤WEEK 3-4: SQL 
Do this:
✔ SQLBolt.com (free, 2 weeks)
✔ Practice on real datasets: Kaggle, data.world
✔ Write 20 queries that answer business questions

➔ Project: Analyze a public dataset (sales, customers, anything)
Post it on LinkedIn with insights in plain English.

╰┈➤WEEK 5-6: Data Visualization
Do this:
✔ Pick ONE: Power BI (most in-demand) or Tableau
✔ Follow Microsoft's free Power BI course
✔ Build 3 dashboards from real data

Post each dashboard on LinkedIn with:
➔ The business problem it solves
➔ One key insight
➔ How you built it

╰┈➤WEEK 7-8: Python Basics 
Do this:
✔ Learn pandas library only (YouTube: "Pandas in 2 hours")
✔ Learn these functions: read_csv, groupby, merge, fillna
✔ Clean one messy dataset

➔ Why: 80% of analyst work is data cleaning. Master this, you're hired.
➔ Project: Take a dirty dataset → Clean it → Visualize it
Document the process on LinkedIn.

╰┈➤WEEK 9-10: AI Automation 
This is what separates you from everyone else.
Learn:
✔ Google Apps Script (automate Google Sheets)
✔ Make.com basics (connect apps without coding)
✔ ChatGPT for analysis (prompt engineering)

➔ Project 1: Build an automated workflow:
▶ Example: Google Form → Auto-populates Sheet → Auto-generates weekly report → Auto-sends email
Post this. Companies are desperate for this skill.

╰┈➤WEEK 11-12: Portfolio + Personal Brand
Do this: Build 3 REAL projects that solve actual problems:
Project 1: Business Dashboard
✔ Use real company data (or public data)
✔ Answer: "What should the CEO know this week?"
✔ Tools: SQL + Power BI

➔ Project 2: Predictive Analysis
▶ Example: "Which customers will churn?"
▶ Tools: Python (pandas) + simple ML model

➔ Project 3: Automation Workflow
▶ Show you can save companies 10 hours/week
▶ Tools: Google Apps Script + Make.com

Post EVERY step on LinkedIn:
✔ The problem you're solving
✔ Your process (even mistakes)
✔ The final result + insights
✔ What you learned

While learning, don't forget to:
➔ Build in Public (15 min/day)
➔ Engage with your Community (15 min/day)
➔ Apply Strategically (After Week 8)

After 90 days you WON'T be:
➔ A senior data scientist
➔ An ML engineer
➔ An expert in everything

After 90 days you WILL be:
➔ Job-ready as a junior analyst
➔ Visible to recruiters
➔ Confident in SQL + one visualization tool
➔ Able to automate basic workflows
➔ Someone with a growing network

That's enough to get hired.
