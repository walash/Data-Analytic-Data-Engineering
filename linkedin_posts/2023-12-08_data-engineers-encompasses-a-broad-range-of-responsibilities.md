## Content

Data Engineers encompasses a broad range of responsibilities related to designing, building, and maintaining data infrastructure and pipelines. 

Key terminologies that data engineering folks must know while diving into day to day activities includes -

ETL/ELT (Extract, Transform, Load)/ Reverse ETL
Data Integration
Data Warehousing
Data Lakes/Marts/Mesh/Fabric
Data Mining
Data Wrangling
BigData
SQL/NoSQL(Databases)
Data Pipelines
Batch Processing
Streaming Processing
Data Quality
Data Lineage
Change Data Capture (CDC)
Orchestration
Metadata Management
Data Modeling
Data Architecture
Data Security
Data Governance

What else would you like to my dear #data #engineering enthusiasts?

By mastering these data engineering concepts focusing on each terminology and its impact, professionals can provide business-critical data infrastructure and power a wide array of analytical applications.
