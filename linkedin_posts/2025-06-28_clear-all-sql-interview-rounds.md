## Content

Clear all SQL interview rounds 

By mastering these 7 SQL patterns

➊ Joins (Combining Data)
↳ Inner, Left, Right, Full Joins
↳ Self Joins and Cross Joins
↳ Combine data from multiple tables efficiently

➋ Window Functions (Analytics Simplified)
↳ ROW_NUMBER, RANK, DENSE_RANK
↳ Aggregate with PARTITION BY and ORDER BY
↳ Solve ranking and cumulative sum problems

➌ Aggregations and Grouping
↳ GROUP BY with HAVING for filtering
↳ COUNT, AVG, SUM, MIN, MAX operations
↳ Nested aggregations for advanced analysis

➍ Subqueries (Query Within a Query)
↳ Correlated vs Non-Correlated Subqueries
↳ Use subqueries in SELECT, FROM, WHERE
↳ Build reusable queries for complex logic

➎ CTEs (Common Table Expressions)
↳ Simplify complex queries with WITH
↳ Recursion for hierarchical data
↳ Enhance readability and maintainability

➏ Data Manipulation (CRUD Operations)
↳ INSERT, UPDATE, DELETE for managing data
↳ Handling duplicates with DISTINCT and MERGE
↳ Optimize operations for performance

➐ Query Optimization (Speed and Efficiency)
↳ Use proper indexes for large datasets
↳ Avoid unnecessary calculations with WHERE
↳ Explain Plans to analyze query performance
