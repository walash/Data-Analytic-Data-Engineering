📍 IF → Performs logic tests (true/false)

📍 IFERROR → Handles errors without breaking your sheet

📍 SUMIFS → Adds values with multiple conditions

📍 COUNTIFS → Counts values with multiple conditions

📍 INDEX MATCH → Powerful data lookup combo

📍 TEXTJOIN → Combines text from multiple cells with a delimiter

📍 FILTER → Dynamically filter data (Excel 365)

📍 SORT → Sort your data dynamically (Excel 365)

📍 UNIQUE → Removes duplicates instantly

📍 LEN/LEFT/RIGHT/ MID → For fast text extraction

📍 CONCAT/TEXTJOIN → Combine multiple cells into one
