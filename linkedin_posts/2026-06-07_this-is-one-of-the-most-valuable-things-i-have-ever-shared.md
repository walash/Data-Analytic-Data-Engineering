10 GitHub repositories every data analyst should bookmark in 2026.

All free. All practical. Better than most paid courses.

Save this before you scroll.

1. awesome-public-datasets
https://lnkd.in/grMvkQ5U
Free real-world datasets across industries. Stop using Titanic.

2. data-science-ipython-notebooks
https://lnkd.in/gsYqmkqK
Run-ready notebooks for Pandas, NumPy, SQL, Matplotlib.

3. SQL-Murder-Mystery
https://lnkd.in/gjPsgFwg
Solve a case using SQL. Learn joins, filters, aggregation.

4. pandas-exercises
https://lnkd.in/gr3mk57D
50+ exercises. Real datasets. No hand-holding.

5. project-based-learning
https://lnkd.in/g-5fB47u
Learn by building real projects, not watching tutorials.

6. Alex Freberg Portfolio Projects
https://lnkd.in/g-89jwwA
Real analyst projects. Strong reference for portfolio quality.

7. SQL-practice-problems
https://lnkd.in/gS-T32yQ

500+ problems from basics to advanced SQL.

8. Python for Data Analysis
https://lnkd.in/g3g7dmU2
By Pandas creator. Definitive, free guide.

9. Data Visualization Catalogue
https://lnkd.in/gVKpgtGX
Pick charts based on purpose, not habit.

10. dbt Jaffle Shop
https://lnkd.in/gykdE4-P
Learn analytics engineering. dbt is becoming essential.
