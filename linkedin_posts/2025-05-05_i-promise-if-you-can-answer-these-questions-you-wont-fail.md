→ What is Amazon S3 and how is it used in data engineering?
→ Difference between S3 Standard vs S3 Glacier vs S3 Intelligent-Tiering?
→ What is AWS Glue, and what are its core components?
→ How do you run ETL jobs in AWS Glue?
→ What is Amazon Redshift? How is it different from traditional RDBMS?
→ What is IAM and why is it important?
→ What are EC2, Lambda, and when do you use them?
→ Difference between RDS and Redshift?
→ How do you schedule jobs using AWS Glue triggers or workflows?
→ What is a VPC, and how does it affect data pipelines?

𝗜𝗻𝘁𝗲𝗿𝗺𝗲𝗱𝗶𝗮𝘁𝗲: 𝗕𝘂𝗶𝗹𝗱𝗶𝗻𝗴 𝗬𝗼𝘂𝗿 𝗦𝗸𝗶𝗹𝗹𝘀
→ What are partitions in AWS Glue and why are they important?
→ How do you optimize performance in Redshift queries?
→ What are Redshift Spectrum and its use case?
→ Difference between AWS Glue DynamicFrame vs DataFrame?
→ How do you handle schema evolution in Glue Catalog?
→ What is AWS Lake Formation?
→ How do you ingest real-time data in AWS (e.g., using Kinesis or MSK)?
→ What’s the role of CloudWatch in monitoring data pipelines?
→ How do you secure sensitive data stored in S3?
→ What is Athena, and how does it work under the hood?
