## Content

I just automated my entire LinkedIn job search using Claude Desktop + Apify.

100+ jobs. Filtered. Sorted. Linked. In under 2 minutes.

Here’s the exact 5-step setup (free) 👇

Step 1 — Download Claude Desktop
claude.ai/download → install → sign in.
(This only works on Desktop, NOT the browser version)

Step 2 — Get your free Apify API key
→ Sign up at apify.com
→ Settings → API & Integrations → copy your token

Step 3 — Connect Apify to Claude
→ Claude Desktop → Settings → Integrations → find Apify → paste token
→ Test it: “List available Apify actors for LinkedIn scraping”
→ If you see results, you’re live ✅

Step 4 — Run this prompt
Change ROLE, LEVEL, LOCATION at the top → paste into Claude → watch it pull 100+ jobs into a dark-mode interactive HTML table with:
🔥 flag for 200+ applicants
🔍 search + filters
↕️ sortable columns
🔗 direct LinkedIn links

Step 5 (bonus) — Attach your resume
Run the same prompt with your resume attached → Claude adds an AI match score for EVERY job based on your actual skills.
Ab sochna nahi, seedha apply karna hai.

Save this post. You’ll need it on your next job hunt.
