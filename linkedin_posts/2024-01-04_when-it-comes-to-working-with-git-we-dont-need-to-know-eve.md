When it comes to working with Git, we don't need to know everything to be effective. Turns out, we use about 20% of the commands 80% of the time! 

Here's a quick list of the Git commands we use day in and day out:

𝗚𝗲𝘁𝘁𝗶𝗻𝗴 𝗦𝘁𝗮𝗿𝘁𝗲𝗱:
- 𝚐𝚒𝚝 𝚌𝚕𝚘𝚗𝚎: Copy a repo to your local machine.

𝗠𝗮𝗸𝗶𝗻𝗴 𝗖𝗵𝗮𝗻𝗴𝗲𝘀:
- 𝚐𝚒𝚝 𝚜𝚝𝚊𝚝𝚞𝚜: See what's changed.
- 𝚐𝚒𝚝 𝚊𝚍𝚍: Tell Git which changes to include in the next commit.
- 𝚐𝚒𝚝 𝚌𝚘𝚖𝚖𝚒𝚝: Save your snapshot of changes.

𝗖𝗼𝗺𝗯𝗶𝗻𝗶𝗻𝗴 𝗪𝗼𝗿𝗸:
- 𝚐𝚒𝚝 𝚖𝚎𝚛𝚐𝚎: Bring two sets of changes together.
- 𝚐𝚒𝚝 𝚜𝚝𝚊𝚜𝚑: Temporarily hide changes that you're not ready to commit.

𝗦𝗵𝗮𝗿𝗶𝗻𝗴 𝗪𝗼𝗿𝗸:
- 𝚐𝚒𝚝 𝚙𝚞𝚕𝚕: Grab the latest updates from the remote repo.
- 𝚐𝚒𝚝 𝚙𝚞𝚜𝚑: Send your changes up for everyone to see.

Remember, mastering these will get you through most of your workday. 

Keep it simple and code on!

Here's a simplified list of other Git commands that you can use as a reference :

Setting Up and Configuring Git:
- 𝚐𝚒𝚝 𝚒𝚗𝚒𝚝: Initialize a new Git repository.
- 𝚐𝚒𝚝 𝚌𝚘𝚗𝚏𝚒𝚐: Set or get configuration settings.

Local Repository Operations:
- 𝚐𝚒𝚝 𝚌𝚕𝚘𝚗𝚎: Create a copy of an existing repository.
- 𝚐𝚒𝚝 𝚊𝚍𝚍: Add files to the staging area.
- 𝚐𝚒𝚝 𝚜𝚝𝚊𝚝𝚞𝚜: Check the status of changes as untracked, modified, or staged.
- 𝚐𝚒𝚝 𝚌𝚘𝚖𝚖𝚒𝚝: Commit your staged content as a new commit snapshot.
- 𝚐𝚒𝚝 𝚍𝚒𝚏𝚏: Show changes between commits, commit and working tree, etc.
- 𝚐𝚒𝚝 𝚛𝚎𝚜𝚎𝚝: Reset current HEAD to the specified state.
- 𝚐𝚒𝚝 𝚛𝚖: Remove files from the working directory and staging area.

Branching and Merging:
- 𝚐𝚒𝚝 𝚋𝚛𝚊𝚗𝚌𝚑: List, create, or delete branches.
- 𝚐𝚒𝚝 𝚌𝚑𝚎𝚌𝚔𝚘𝚞𝚝: Switch branches or restore working tree files.
- 𝚐𝚒𝚝 𝚖𝚎𝚛𝚐𝚎: Join two or more development histories together.
- 𝚐𝚒𝚝 𝚖𝚎𝚛𝚐𝚎𝚝𝚘𝚘𝚕: Run merge conflict resolution tools to resolve merge conflicts.
- 𝚐𝚒𝚝 𝚕𝚘𝚐: Show commit logs.
- 𝚐𝚒𝚝 𝚜𝚝𝚊𝚜𝚑: Stash the changes in a dirty working directory.

Sharing and Updating Projects:
- 𝚐𝚒𝚝 𝚏𝚎𝚝𝚌𝚑: Download objects and refs from another repository.
- 𝚐𝚒𝚝 𝚙𝚞𝚕𝚕: Fetch from and integrate with another repository or a local branch.
- 𝚐𝚒𝚝 𝚙𝚞𝚜𝚑: Update remote refs along with associated objects.

Inspection and Comparison:
- 𝚐𝚒𝚝 𝚕𝚘𝚐: Show commit logs.
- 𝚐𝚒𝚝 𝚜𝚝𝚊𝚝𝚞𝚜: Show the working tree status.
- 𝚐𝚒𝚝 𝚍𝚒𝚏𝚏: Show changes between commits, commit and working tree, etc.

Debugging:
- 𝚐𝚒𝚝 𝚋𝚒𝚜𝚎𝚌𝚝: Use binary search to find the commit that introduced a bug.

Synchronization:
- 𝚐𝚒𝚝 𝚛𝚎𝚖𝚘𝚝𝚎: Manage set of tracked repositories.
